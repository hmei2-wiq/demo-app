# Architecture

Status: DRAFT

```
Expo app (React Native)  --HTTP/JSON-->  FreshCart API (node:http)  -->  products.json (seed), orders[] (memory)
  cart + lists in AsyncStorage            stateless quote + order placement
```

## Responsibilities
- **API owns pricing.** The app sends `{productId, qty}` lines; the API returns line totals, savings, fee and total in integer cents. The app never computes totals itself.
- **App owns cart and lists.** Stored on device; no accounts.
- **Slots** are generated by the API from the current time: 2-hour windows (08:00 to 20:00) for the next 3 days, only those starting at least 2 hours from now.

## Endpoints
| Method | Path | Purpose |
|---|---|---|
| GET | /api/health | liveness |
| GET | /api/categories | category list |
| GET | /api/products?category=&q=&special=1 | browse, search, specials |
| GET | /api/products/:id | detail |
| GET | /api/slots?type=pickup\|delivery | available slots |
| POST | /api/quote | price a basket |
| POST | /api/orders | place order |
| GET | /api/orders | order history (all, preview) |

## Money
Integer cents, AUD. Delivery fee 800 when subtotal under 10000; free at or above. Pickup free.

## Errors
JSON `{ "error": "message", "code": "SNAKE_CASE" }` with 400, 404 or 413.

## Security notes (preview)
Body limit 100 KB; all input validated; no secrets; CORS open for local dev only.
